# ML Engineer Portfolio: RAG Assistant

Это пример проекта Retrieval-Augmented Generation (RAG) для портфолио ML-инженера.
Проект представляет собой умного ИИ-ассистента, который может отвечать на вопросы по документации (FAQ) дебетовой карты T-Black (Т-Банк).

## Архитектура
1. **Сбор данных:** Асинхронный парсинг HTML страниц с помощью `aiohttp` и извлечение чистого текста через `html2text`. Ссылки берутся из файла `urls.txt`.
2. **Chunking & Embeddings:** Текст разбивается на чанки с помощью LangChain (`RecursiveCharacterTextSplitter`). Эмбеддинги генерируются бесплатной мультиязычной моделью от HuggingFace (`sentence-transformers`).
3. **Vector Database:** В качестве хранилища знаний используется векторная СУБД `Chroma`.
4. **LLM Generation:** В качестве мозга бота выступает модель Llama 3 (через API `Groq`), которая обеспечивает быстрый inference. Она получает промпт вместе с найденными кусками текста и генерирует ответ без "галлюцинаций".
5. **UI:** Интерфейс построен на `Streamlit`.

## Структура проекта
- `urls.txt` — список ссылок на статьи для парсинга (добавьте свои ссылки с новой строки).
- `src/ingest.py` — скрипт для асинхронного парсинга и разбивки текстов.
- `src/rag.py` — логика RAG: создание базы данных, настройка ретривера и цепочки генерации (LangChain LCEL).
- `src/app.py` — интерфейс (чат-бот) на Streamlit.

## Как запустить

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Добавьте ссылки на статьи в файл `urls.txt`.

3. Запустите скрипт создания базы знаний:
```bash
PYTHONPATH=src python -c "from rag import create_vector_db; create_vector_db()"
```
*Это скачает тексты по вашим ссылкам, разобьет их на чанки и создаст папку `chroma_db` с локальной базой векторов.*

*(Можно также просто запустить `PYTHONPATH=src python src/rag.py`, так как там есть вызов `create_vector_db()` внутри `if __name__ == "__main__":`, а затем примеры тестовых запросов).*

4. Настройте API-ключ:
Скопируйте `.env.example` в `.env` и впишите туда ваш ключ `GROQ_API_KEY`. (Или введите его прямо в веб-интерфейсе).

4. Запустите веб-приложение:
```bash
PYTHONPATH=src streamlit run src/app.py
```
